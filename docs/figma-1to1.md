# Как получить 1:1 — бесплатно

Проверено 2026-10-25. Ниже два способа, оба не требуют платного тарифа.

## Почему одного Figma Desktop мало

| Что нужно | Требование Figma | Твоё состояние |
|---|---|---|
| Desktop MCP-сервер | включается **из панели Dev Mode** | — |
| Dev Mode | Professional+ и seat Full/Dev | `x-figma-plan-tier: starter` |
| REST API `/files`, `/nodes` | лимит на Starter | `Retry-After: 305050` (~3.5 сут) |

Десктопное приложение только открывает файл. MCP живёт в Dev Mode, а Dev Mode на
Starter недоступен. Ставить десктоп **можно** (пригодится для пункта 1), но сам
по себе он ничего не даёт.

---

## Способ 1 — снять «Outline text» при экспорте SVG

Сейчас в твоих SVG: `<text>` = 0, `font-family` = пусто. Весь текст переведён в
кривые, поэтому шрифт заголовка приходится угадывать — из-за этого заголовок
выходил 1962px вместо 1440.

**Что сделать:** выделить фрейм → Export → SVG → в настройках снять
**Outline text** → экспортировать заново.

В файле появятся живые:

```svg
<text font-family="Helvetica Neue" font-size="15" font-weight="300"
      letter-spacing="-0.4">AutoDNA Service</text>
```

После этого не нужно ни MCP, ни плагина — значения читаются прямо из SVG.

## Способ 2 — плагин `figma-plugin/` (даёт больше, чем MCP)

Плагин выгружает дерево узлов в JSON: координаты, отступы, радиусы, заливки,
обводки, эффекты, и для каждого текста — семейство, вес, кегль, интерлиньяж,
трекинг и сами символы. Это ровно то, что отдаёт MCP `get_design_context`,
только бесплатно и без лимитов.

### Установка (2 минуты)

1. Открыть Figma (браузер или десктоп — без разницы).
2. Меню слева вверху → **Plugins → Development → Import plugin from manifest…**
3. Выбрать `figma-plugin/manifest.json`.
4. Плагин появится в **Plugins → Development** как `AutoDNA dump node tree`.

Важно: меню **Development** существует только после первого импорта — пустым
Figma его не показывает. Если пункта нет совсем, обходной путь: **Plugins →
Development → Create new plugin** (Figma создаст манифест), затем заменить в нём
`main` на `code.js` и добавить `"ui": "ui.html"`.

Манифест обязан содержать `ui`, иначе `__html__` не определён и плагин падает
с `ReferenceError` на первой строке. Также нужны `id` и
`"documentAccess": "dynamic-page"`.

### Использование

1. Выделить фрейм (например `main`, `Menu`, `Component 7`).
2. **Plugins → Development → AutoDNA — dump node tree**.
3. Нажать **Dump selected frame(s)**.
4. Кликнуть по полю с JSON — он скопируется.
5. Сохранить как `AUTODNA/nodes-<имя-фрейма>.json` в проект.

### Что придёт

```json
{
  "name": "AutoDNA Service",
  "type": "TEXT",
  "abs": { "x": 1149, "y": 376, "w": 141, "h": 15 },
  "rel": { "x": 2, "y": 181 },
  "text": "AutoDNA Service",
  "font": {
    "family": "Helvetica Neue", "weight": 300, "size": 15,
    "lineHeight": 15, "letterSpacing": -0.4, "letterSpacingUnit": "PIXELS"
  },
  "fills": [{ "type": "solid", "color": "#ffffff", "opacity": 1 }]
}
```

`rel` — позиция относительно фрейма, то есть готовое `left`/`top` в CSS.
Такие же данные придут для контейнеров: `layout.gap`, `layout.pad`, `radius`,
`effects` (тени и блюр), `opacity`.

## Что я сделаю, когда пришлёшь данные

1. Сверю каждый блок страницы с JSON и выпишу расхождения.
2. Заменю подбор шрифта на значения из `font`.
3. Пересоберу координаты из `rel`, отступы из `layout`.
4. Прогоню замер DOM против JSON — расхождение должно стать нулевым.

## Что это НЕ решит

Геометрические фигуры фона в хиро (`Ellipse 3`, огромный градиент 4272×533) —
это векторные слои. Они уже отрисованы точно, потому что хиро рендерит сам
артворк. JSON нужен для **остальных секций** и для текста.
