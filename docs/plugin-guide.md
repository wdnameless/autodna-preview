# Гайд: установить плагин и выгрузить доску

Плагин лежит в `figma-plugin/` этого проекта. Файлы:

```
figma-plugin/
  manifest.json    описание плагина
  code.js          обход дерева слоёв
  ui.html          панель с кнопкой
  test/mock-figma.cjs  проверка без Figma: node mock-figma.cjs
```

Проверен 2026-10-26 на моке документированного Plugin API: шрифты (семейство,
вес, кегль, интерлиньяж, трекинг), сегменты смешанных стилей, градиенты,
IMAGE-заливки, радиусы, тени, auto-layout, пустая страница и мультиселект.
Старый баг (`font: {}` из-за несуществующего `.style`) воспроизведён на моке
и исправлен — чтением полей напрямую с ноды.

---

## Шаг 1. Открыть файл в режиме редактирования

Плагины **не работают в view-only**. Признак: `Plugins` в меню серое и при
наведении написано «Can't use plugins in view-only files».

Ты уже сохранил копию в Drafts — открой именно её: в списке файлов это
**AUTODNA (Copy)**, слева вверху должно быть `Drafts · Free`, а не `View only`.
Кнопка **Share** справа сверху должна быть синей, не серой.

---

## Шаг 2. Импортировать плагин

1. Внутри открытого файла нажми на **иконку Figma** в самом левом верхнем углу
   (не логотип вкладки, а кнопка меню над панелью слоёв).
2. В меню выбери **Plugins → Development**.
3. Нажми **Import plugin from manifest…**
4. В диалоге выбора файла вставь путь целиком в поле «Имя файла»:

```
C:\Users\Administrator\Desktop\верстка\figma-plugin\manifest.json
```

5. Нажми **Открыть**.

Figma покажет «Plugin imported». Появится файл `manifest.json` — это нормально,
устанавливается именно он.

> Если пункта **Plugins** в меню нет вообще — файл всё ещё read-only.
> Если есть **Plugins**, но нет **Development** — он появится после первого
> импорта; нажми **Create new plugin** и в созданном манифесте замени
> `"main"` и `"ui"` на пути к моим файлам.

---

## Шаг 3. Запустить

1. Снова **Plugins → Development → AutoDNA dump node tree**.
2. Откроется панель 420×460.
3. Нажми **Dump selected frame(s)**.

Выделять ничего не обязательно: если ничего не выбрано, плагин выгрузит
**все фреймы страницы** (`main`, `Menu`, `Component 7`, `Component 8`,
мобильные — всё, что является фреймом). Текстовые слои он пропускает.

Если нужен только один фрейм — сначала выдели его, тогда выгрузится только он.

---

## Шаг 4. Забрать JSON

После нажатия кнопки в поле появится JSON и подпись вида
`3 frame(s), 245831 characters. Click the box to copy.`

**Кликни по полю** — текст скопируется в буфер (выделение и Ctrl+C тоже работают).

Сохрани в проект:

```
AUTODNA/nodes-main.json
```

Или просто вставь содержимое в чат — я разберу.

---

## Что внутри JSON

Для каждого узла:

```json
{
  "name": "AutoDNA Service",
  "type": "TEXT",
  "abs": { "x": 1149, "y": 376, "w": 141, "h": 15 },
  "rel": { "x": 2, "y": 181 },
  "text": "AutoDNA Service",
  "font": {
    "family": "Helvetica Neue",
    "weight": 300,
    "size": 15,
    "lineHeight": 15,
    "letterSpacing": -0.4,
    "letterSpacingUnit": "PIXELS"
  },
  "fills": [{ "type": "solid", "color": "#ffffff", "opacity": 1 }]
}
```

| Поле | Зачем |
|---|---|
| `abs` | абсолютные координаты на доске |
| `rel` | позиция внутри фрейма = готовое `left` / `top` |
| `font` | семейство, вес, кегль, интерлиньяж, трекинг |
| `fills` / `strokes` | цвет, прозрачность, градиенты |
| `radius`, `effects`, `opacity` | скругления, тени, блюр, прозрачность |
| `layout` | `gap` и `padding`, если фрейм на auto layout |

---

## Что я сделаю с файлом

1. Сверю каждый блок с JSON и выпишу расхождения.
2. Заменю подбор шрифтов значениями из `font` — сейчас заголовок набран
   Orbitron 138px, а на доске другой шрифт; из JSON будет точный.
3. Пересоберу координаты из `rel`, отступы из `layout`.
4. Прогоню замер DOM против JSON — расхождение должно стать нулевым.

---

## Если что-то пошло не так

| Симптом | Причина | Решение |
|---|---|---|
| `Plugins` серое | файл read-only | открыть копию в Drafts |
| Плагина нет в списке | не импортирован | шаг 2 |
| Панель пустая, ошибок нет | старый `manifest.json` без `ui` | файл уже исправлен, импортируй заново |
| `Select at least one frame first` | старая версия `code.js` | файл обновлён, импортируй заново |
| `ReferenceError: __html__` | в манифесте нет `ui` | то же самое |
