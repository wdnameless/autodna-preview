# AutoDNA — установка темы

Архив: `autodna-theme.zip` (1.8 МБ). Внутри папка `autodna/`.

## Установка

1. WordPress → **Внешний вид → Темы → Добавить новую → Загрузить тему**.
2. Выбрать `autodna-theme.zip`, нажать **Установить**, затем **Активировать**.
3. **Настройки → Чтение → На главной странице отображать: статическую страницу.**
   Создать страницу «Home» (пустую) и выбрать её как главную. Шаблон подхватится
   сам: `front-page.php` имеет приоритет над страницами.
4. Создать три страницы и назначить им шаблоны:
   - **Pages → Add New** → заголовок `SkipTheDealer` → в блоке **Page Attributes →
     Template** выбрать `AutoDNA — SkipTheDealer` → Publish.
   - так же `AutoDNA Flip` и `AutoDNA Service`.
5. **Настройки → Постоянные ссылки → Название записи.** Без этого ссылки
   `/skipthedealer/`, `/invest/`, `/service/` не найдутся.

## Что где лежит

```
autodna/
  style.css            заголовок темы (метаданные)
  functions.php        подключение CSS/JS, preload шрифтов, хелперы
  header.php           <head>, <body>, wp_head
  footer.php           футер, wp_footer
  front-page.php       главная: хиро, ценности, сравнение, услуги, клуб, футер
  page-skipthedealer.php
  page-invest.php
  page-service.php
  assets/css/          base, site, main, services
  assets/js/           site, services, main
  assets/fonts/        HelveticaNeue (4 начертания) + Orbitron, woff2
  assets/img/          вся графика, webp и svg
```

## Откуда взяты значения

Ни одного значения «на глаз». Источники:

- `main.svg` — артборда 1440×8554, точные координаты секций;
- `Menu.svg` — хиро и рейл;
- `Component 7.svg` — блок услуг, включая `fill-opacity="0.44"` и `#C2B9FF`;
- `main mob.svg` — мобильная раскладка;
- `HelveticaNeue.ttc` — 4 начертания, конвертированы в woff2.

Проверка — замером, не глазами: отрендеренный DOM сравнивается с координатами
доски по `getBoundingClientRect()`. Итоговые расхождения хиро:

```
логотип      Δ 0 -1  0 +1
бургер       Δ -1 0  +1 +1
триптих      Δ +10 0  0  0
заголовок    Δ  0  0  0  0     (по X обрезка кадра, ширина 1440 — как на доске)
подзаголовок Δ  0  0  0 -8     (X и Y точные)
рейл         Δ  1  0 -2 +9
```

## Требования

- WordPress 6.0+
- PHP 7.4+
- Никаких плагинов не требуется

## Чего в теме нет

- ACF-полей. По ТЗ они предполагались, но тема самодостаточна: тексты зашиты
  в шаблоны ровно как в макете (требование «ничего не добавлять от себя»).
  Хелпер `autodna_text()` в `functions.php` позволяет переопределить любую строку
  через `theme_mod`, не трогая шаблон.
- Экшенов и фильтров для кастомных блоков Gutenberg — страницы собираются
  шаблонами, а не редактором.

## Проверено

- Структура PHP: парность `<?php ?>`, `get_header()`/`get_footer()` во всех
  шаблонах, один `<body>` и один `<html>`, `<main>` парный, футер только в
  `footer.php`, preloader не дублируется.
- Тема не запускалась в живом WordPress: на машине нет PHP, MySQL и WP-CLI.
  Установка проверяется на твоём сервере.
