## Требование №1: ничего не добавлять от себя
Верстка — точная выборка из доски. Запрещено:
- придумывать секции, блоки, тексты, цифры, которых нет в макете
- менять порядок блоков
- подбирать шрифты/цвета «на глаз» — только значения из доски
- добавлять свои заголовки, CTA, иконки, декор

## Требование №2: 1:1 по пикселям
Каждый элемент ставится на координаты из Figma (`absoluteBoundingBox`), с её же
типографикой (`style`: fontFamily, fontSize, fontWeight, letterSpacing, lineHeight).
Фоны и графика — экспорт слоёв из Figma, а не CSS-градиенты по мотивам.

## Требование №3: WordPress
Готовые 4 страницы упаковать в устанавливаемую тему:
- `header.php` / `footer.php` / `functions.php`
- 4 шаблона страниц с `Template Name`
- ACF-поля для редактируемых текстов (с fallback на значения из макета)
- `README-INSTALL.md`
- архив `autodna-theme.zip` с папкой `autodna/` в корне

## Требование №4: адаптив
Мобильные фреймы на доске: `main mob`, `SkipTheDealer mob`, `Invest in cars mob`,
`The future of service mob` (ширина 393). Собрать по ним же, тем же способом.

## Как проверяется
- Скриншот страницы против экспорта фрейма: расхождение по пикселям
- Поиск любого текста страницы в доске: не должно быть ни одного текста,
  которого нет в Figma
- Высота страницы равна высоте фрейма (±2px)
