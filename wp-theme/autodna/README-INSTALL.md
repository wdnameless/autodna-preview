# Autodna — установка темы

Тема собрана из четырёх страниц, сгенерированных прямо из дерева Figma: каждый текстовый
слой стоит на координатах макета, пиксельная основа взята из экспорта фрейма.

## Что нужно
- WordPress 6.0+, PHP 7.4+
- Плагин **Advanced Custom Fields** — опционально. Без него тема работает: все значения
  уже зашиты в разметку как fallback.

## Установка
1. Внешний вид → Темы → Добавить новую → Загрузить тему → `autodna-theme.zip` → Установить.
2. Активировать.
3. Создать четыре страницы и назначить им шаблоны:

| Страница | Ярлык (slug) | Шаблон |
|---|---|---|
| Главная | `home` — назначить статичной главной в Настройки → Чтение | Autodna — Home |
| SkipTheDealer | `skipthedealer` | Autodna — SkipTheDealer |
| Invest in cars | `invest` | Autodna — DNA Flip |
| The future of service | `service` | Autodna — DNA Service |

4. Меню (по желанию): Внешний вид → Меню → область `Primary Navigation`.

## Как устроен шаблон
Каждый шаблон — это рамка фиксированного размера, равная размеру фрейма на доске
(`data-frame`). Внутри:
- `img.base` — пиксельная основа страницы (экспорт фрейма),
- `<p>` — текстовые слои на абсолютных координатах со стилями из Figma.

При ширине окна меньше 1440px рамка масштабируется как единое целое, сохраняя пропорции.

## Замена контента
Текст правится в шаблоне напрямую либо через ACF-группу «DNA — Contacts» (контакты и соцсети).
Картинка-основа лежит в `assets/<page>/base.jpg` — при обновлении макета её нужно
перегенерировать командой `python tools/render.py <page>` в исходном репозитории.

## Шрифты
Orbitron и DM Sans подключены с Google Fonts. Helvetica Neue — лицензионный шрифт,
используется системный fallback; положите `woff2` в `assets/fonts/` и добавьте
`@font-face` в `style.css`, если нужен полный 1:1.

## Известные ограничения
- Мобильные фреймы (393px) в тему пока не включены.
- Пиксельная основа — растр: фотографии не являются отдельными заменяемыми файлами.
